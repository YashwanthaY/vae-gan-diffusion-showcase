- **Research Repository:** [Vae-Gan-Diffusion-study](https://github.com/RAYS/Vae-Gan-Diffusion-study)
- **Live Model Demo (HF Spaces):** [vae-gan-diffusion-demo](https://huggingface.co/spaces/Yashwantha123/vae-gan-diffusion-demo)

---

## 🔬 Research Overview

This application acts as a visual and interactive interface for a quantitative comparative study on generative models:

1. **β-VAE**: Learns a continuous latent distribution using KL-divergence regularization.
2. **WGAN-GP**: Adversarial generator-discriminator framework with gradient penalty for training stability.
3. **DDPM (Diffusion)**: Iterative denoising model with classifier-free guidance (s=1.5) and 500 DDIM sampling steps.

### 📊 Key Finding: Downstream Classifier Data Replacement
A ResNet-18 classifier trained **entirely on synthetic images** generated by DDPM reached **57.10% ± 0.91%** test accuracy on real CIFAR-10 images, compared to **58.93% ± 2.89%** for a classifier trained on real images — a statistically indistinguishable performance (paired t-test, $p < 0.0001$, across 5 seeds).

## ⚡ Key Application Features

- **3D Animated Hero Scene (Three.js / React Three Fiber)**: Real-time particle clouds and 3D geometric morphing corresponding to selected model architectures.
- **Quantitative Benchmark Matrix**: Dynamic Chart.js plots comparing FID, Inception Score, and loss formulations.
- **Default Pre-Generated Static Gallery**: Uniform 1:1 square sample grids loading instantly with zero backend API dependency.
- **Live GPU Model Inference Console**: Connected via `@gradio/client` to the Hugging Face ZeroGPU backend with interactive sliders for DDIM steps, guidance scale (CFG), and super-resolution upscaling.
- **Web Audio API Synthesizer**: Native sound effects and pitch-bent chimes during tab switches and live model execution.
- **Interactive Debugging Journey**: 6 non-obvious engineering post-mortems documenting root-cause fixes, mathematical proofs, and code patches.

## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/RAYS/vae-gan-diffusion-showcase.git
   cd vae-gan-diffusion-showcase
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
